# SC-011 진행 · 정가 근거 등록과 검토

2026-09-29 · 상태: 일부 구현. 가격 유형 전체의 표시 계약이나 소비자 공개 재개는 아직 아니다.

## 구현한 계약

- 기존 `trims.base_price`는 출처가 없으므로 검증 가격으로 승격하거나 이관하지 않는다. 별도 `trim_msrp_evidence`에 트림, 원화 금액, 원문 HTTPS 주소, 원문 위치, 확인 시각, 적용 기간, 초안/검증/철회 상태, 검토자와 검토 시각을 저장한다.
- 관리자는 `/admin/price-evidence`에서 초안을 작성하고 원문 대조 후 공개하거나 철회한다. 직접 상태 칼럼을 수정하는 권한은 없다. 모든 공개/철회 전이는 `trim_msrp_review_events`에 남는다. 한 트림에는 검증 상태 행을 동시에 하나만 둘 수 있다.
- 공개용 `current_trim_msrp`는 검증 상태이고 적용 기간 안에 있으며 검토 후 30일이 지나지 않은 값만 반환한다. 검토자 계정 식별자와 초안은 공개하지 않는다. 30일 뒤에는 자동으로 조회 결과에서 빠지며, 새 가격표를 다시 등록·검토해야 한다.
- 원문 URL의 제조사 소유 여부와 가격표 내용 자체는 자동 검증하지 않는다. 이는 관리자의 수동 대조 책임이다. 원본 파일 저장·해시 검증도 이번 단계에 포함되지 않았다.

## 검증과 운영 경계

- 빈 로컬 Supabase DB에 전체 마이그레이션 적용 후 `supabase/tests/reviewed-trim-msrp.sql` 통과: 일반 계정의 작성/공개 거부, 관리자 초안/공개/철회, 공개 필드 제한, 중복 검증 차단, 30일 재검토 만료, 전이 기록을 확인했다. 테스트 기록은 트랜잭션 롤백한다.
- 타입 검사와 앱 빌드를 통과했다. 관리자 UI는 운영 계정/운영 DB에 대한 통합 검증을 아직 하지 못했다.
- 소비자 가격 UI는 [검수 안내 게이트](./PRICE_PROVENANCE.md) 뒤에 그대로 둔다. `current_trim_msrp`의 실제 출처 검증과 공식 혜택·계약 제보·추정 가격의 개별 계약, 운영 예시 데이터 감사가 끝날 때까지 게이트를 열지 않는다.
- 운영에는 DB 마이그레이션을 먼저 적용해야 관리자 화면이 동작한다. 이 브랜치를 `main`에 병합하는 것만으로 운영 DB 적용이 증명되지는 않는다.
