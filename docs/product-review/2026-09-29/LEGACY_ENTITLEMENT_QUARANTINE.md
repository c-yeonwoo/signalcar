# SC-017 선행 조치 · 과거 열람권 격리

2026-09-29 · 상태: 부분 완료. 결제·환불·이전 권한 이관을 포함한 서버 장부는 아직 없다.

기존 `report_unlocks`에는 지급의 근거가 된 검증 제보 ID나 결제·환불 ID가 없다. 과거에는 검증 전 제보로도 행이 만들어졌고, `purchase`라는 source도 실제 결제 내역을 증명하지 않는다. 따라서 기존 행을 소비자 열람 권한으로 해석하지 않는다.

- 제보 INSERT/검증 상태 변경에 따라 `report_unlocks`를 자동 생성하던 트리거와 함수를 제거했다. 동시 차감이 안전하지 않았던 `unlock_briefing_with_credit` RPC도 제거했다.
- 기존 행은 삭제·재분류하지 않고 service role 감사용으로 보존한다. 일반 계정의 `report_unlocks` 직접 조회·삽입 권한과 본인 조회 정책을 없앴다. 현재 협상 리포트 공개 화면도 계속 닫혀 있다.
- 격리 DB 테스트는 이전 행 보존, 검증된 신규 제보에서도 자동 열람권 미발급, 일반 계정 접근 거부, 레거시 함수·트리거 부재를 확인한다.

열람권 또는 유료 검토를 다시 열기 전에 실제 주문·결제·환불 사건과 권한의 1:1 근거, 중복 webhook/동시 차감, 취소·환불 시 회수, 기존 행의 개별 감사·고객 대응 정책이 필요하다. 운영 DB 적용과 과거 권한 감사는 운영 접근이 없어 아직 확인하지 못했다.
