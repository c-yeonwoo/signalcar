# SC-015/018 선행 수정 · 신규 가입 중단과 기존 기록 접근

2026-09-29 · 상태: 부분 완료. 법무 승인 또는 정식 운영 정책 확정이 아니다.

- 이메일 신규 가입 버튼을 앱 로그인 화면에서 숨겼다. 기존 이메일·Google 계정의 로그인과 비밀번호 재설정은 유지했다. 초안 약관/처리방침을 계속 사용하면 동의한 것으로 간주한다는 문구를 삭제했다.
- 소비자 접수는 중단하되 기존 견적 진단 기록의 열람·삭제는 막지 않도록 `/diagnose`를 다시 열었다. 업로드 폼은 표시하지 않는다. 이용자가 기존 파일을 삭제할 수 있는지 실제 계정으로 운영 검증해야 한다.
- 이용약관의 가짜 `.example` 문의 이메일과 오래된 최종 수정일을 없애고, 검토 중인 초안임을 명시했다. 관리자 계약 제보 화면의 ‘모두 실계약가’·‘공유 폼 없음’ 문구를 정정했다.

남은 조건: 실제 사업 주체·문의처·개인정보 처리/보관·삭제 절차, 정식 약관/환불/유료 검토 운영, 실제 계정 비밀번호 복구·진단 삭제 종단 간 확인. 이메일 신규 가입 버튼 차단은 앱 UI 수준이다. Google OAuth가 새 계정을 생성하는지와 인증 서버의 외부 API 가입 정책은 운영 설정 확인이 필요하다. SC-015와 SC-018은 완료로 표시하지 않는다.
