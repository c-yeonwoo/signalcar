# SC-013 카탈로그 상태 분리

2026-09-29 구현·검증 기록.

- 홈·탐색·비교에서 차량 로딩, DB 연결 실패, 공개 차량 0건을 구분한다. 연결 실패 화면에는 재시도 동작이 있다.
- 탐색 필터 결과 0건은 검색어·조건을 조정하도록 안내한다. 공개 차량 0건은 필터 결과와 별도 화면이다.
- 차량 상세 직접 진입에서 알 수 없는 차량은 현재 제공 범위를 안내하고 탐색으로 이동시킨다. DB 오류는 별도 재시도 화면으로 보인다.
- 차량 목록 쿼리 오류를 빈 배열로 바꾸지 않는다. 카탈로그·시그널 띠가 같은 쿼리 결과를 쓰며, 상세가 없는 듯 보이던 중복 분류를 제거했다.

검증: `npx tsc --noEmit`, 변경 파일 ESLint(기존 Prettier 규칙 제외), `npm run build` 통과. 로컬 브라우저에서 홈·탐색·비교·차량 상세 연결 실패 화면을 확인했다. 실제 운영 DB는 현재 호스트에서 연결되지 않아 정상 차량 목록 및 공개 차량 0건은 운영 데이터로 재현하지 못했다. 해당 확인은 SC-010의 운영 접근 확보 후 수행한다.
